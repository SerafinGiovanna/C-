  ## Escudos
   A Estrela da Morte está sob 
ataque! Para proteger a base, os 
sistemas de defesa automáticos 
precisam ser ativados somente se 
a ameaça for real. 
Você, o(a) programador(a) 
mais confiável do Império, recebeu 
a seguinte missão: dado o nível de 
ameaça detectado por sensores da 
base (um valor inteiro de 0 a 100), 
diga se os escudos devem ser 
ativados. 

A ativação dos escudos acontece apenas quando o nível de ameaça for maior 
ou igual a 50.

**Entrada**  
Um único número inteiro N (0 ≤ N ≤ 100), representando o nível de ameaça 
detectado. 

**Saída**  
A saída será composta pela string “Ativar escudos” se o nível de ameaça for 
maior ou igual a 50, ou pela string "Susse no musse", caso contrário. 

**Exemplos**

| **Entrada** | **Saída**    |
|-------------|--------------|
| 75          | Ativar escudos|
| 25          | Susse no musse|
